### Audit kandidat lokal (21 September 2026)

Saya mengambil [mirror KFGQPC-Madinah-Mushaf](https://github.com/manaf/KFGQPC-Madinah-Mushaf) pada commit `dad9cf67588ab66c914c155924d8a3699704a03d` **di luar repository** sebagai bahan evaluasi. Dua berkas SQLite QUL dalam mirror dan 604 JSON turunannya dapat diakses. `python3 scripts/validate_mushaf_candidate.py /path/to/bundle` memeriksa kelengkapan halaman/baris, urutan surah–ayat–kata, satu penanda untuk tiap ayat, rentang ID kata tiap baris, serta kesesuaian JSON dengan SQLite. Hasil: 604 halaman, 9.060 baris termasuk 14 baris kosong, 114 surah, 6.236 ayat, 83.668 token termasuk penanda, dan 77.432 kata bacaan. Uji perubahan sengaja pada ID kata halaman 1 ditolak validator.

SHA-256 arsip layout: `697cbc7f16db1f56b6d95c4d11a9eea074ad4759babd2d75abcad5738e2fdf96`; arsip kata: `64b59c7ae3dae32f3650c534cb5a40c91089e0a6319372ded9500181a3cc6a47`; digest gabungan 604 berkas JSON dalam urutan halaman: `c1c4f6c5621f3f5af259003a0ab3e2a80b7411b3030b6a249f588303af04276d`. Digest gabungan menghitung konkatenasi byte persis setiap JSON dari halaman 001 sampai 604, bukan checksum resmi penerbit. Render lokal sementara halaman 1 dan 5 menunjukkan font kandidat memuat glyph, tetapi header sengaja diganti label biasa dan hasilnya belum dibandingkan dengan cetakan. Berkas mirror bukan unduhan langsung dari QUL/KFGQPC; klaim lisensi mirror tidak membuktikan hak atas data dan font turunannya. **Tidak ada aset kandidat yang diimpor ke database atau dikomit ke proyek.** Audit ini belum memeriksa kebenaran teks Arab, glyph terhadap cetakan, atau hukum penggunaannya.

### Pemeriksaan silang pratinjau publik (21 September 2026)

`python3 scripts/compare_mushaf_live_samples.py /tmp/tahfidz-source-review` membandingkan urutan pasangan **lokasi kata + glyph** JSON lokal dengan pratinjau langsung [QUL KFGQPC V2](https://qul.tarteel.ai/resources/mushaf-layout/10). Halaman [1](https://qul.tarteel.ai/resources/mushaf-layout/10?page=1), [2](https://qul.tarteel.ai/resources/mushaf-layout/10?page=2), [302](https://qul.tarteel.ai/resources/mushaf-layout/10?page=302), [303](https://qul.tarteel.ai/resources/mushaf-layout/10?page=303), dan [604](https://qul.tarteel.ai/resources/mushaf-layout/10?page=604) cocok seluruhnya: masing-masing 36, 41, 147, 174, dan 73 token. `data-word-id` pada HTML QUL adalah ID CMS yang berbeda dari ID ekspor SQLite; ia **tidak** digunakan sebagai jangkar penilaian. Pemeriksaan ini hanya membuktikan kesamaan sampel kandidat dengan pratinjau sumber yang sama, bukan pembuktian independen kebenaran teks atau kesesuaian dengan mushaf guru.

Klik unduhan SQLite di halaman QUL meminta login. [FAQ QUL](https://qul.tarteel.ai/faq) menyatakan lisensi tiap sumber dapat berbeda dan harus diperiksa per sumber; halaman layout, script, dan font yang ditinjau tidak memuat izin eksplisit untuk menyimpan permanen, mendistribusikan, atau memasukkan aset ke backup aplikasi. Arsip `Al_Madinah_Mushaf_Win_Setup-2.1.zip` dalam mirror lokal hanya berisi teks 134 byte, bukan ZIP sah, sehingga tidak dapat digunakan sebagai bukti paket resmi. Jalur [Quran Foundation](https://api-docs.quran.foundation/legal/developer-terms/) memiliki syarat akun aktif, atribusi, dan batas penyimpanan data; [Content Sync](https://api-docs.quran.foundation/docs/tutorials/content-sync/getting-started/) dapat menjadi pengecualian untuk layout `mushafs` dengan sinkronisasi berkala, tetapi belum diuji karena tidak ada kredensial dan kesesuaian edisi belum ditetapkan.

**Keputusan gerbang F2: belum lulus untuk produksi.** Guru menyatakan halaman 1, 2, 302, 303, dan 604 pada pratinjau QUL V2 cocok dengan pembagian ayat dan baris mushaf fisiknya; tahun cetak fisik tetap belum diketahui. Langkah yang tersisa adalah memperoleh aset berizin langsung dari penerbit/penyedia beserta pernyataan cakupan distribusi/cache/backup dan checksum, lalu meninjau visual serta teks secara menyeluruh oleh guru yang kompeten, termasuk peralihan surah/juz dan beberapa halaman acak. Jangan menandai `validated` atau `active` dan jangan mengimpor aset mirror sampai bukti itu tersedia.

Prototipe di `/mushaf/prototype` memakai **metadata sintetis** lima halaman contoh (1, 2, 302, 303, 604), bukan teks Al-Qur’an dan bukan layout Madinah. Nomor/jangkar contoh menguji navigasi, identitas kata lintas baris/halaman, RTL, perbesaran, dan tampilan ayat adaptif. Halaman ini tidak boleh dipakai untuk penilaian.

Sebelum impor produksi: peroleh paket teks, font, dan layout dari sumber resmi/berizin; catat nama edisi, cetakan/revisi, asal dan versi setiap aset, URL/pernyataan izin, kebijakan distribusi/cache/backup, atribusi, ukuran file dan SHA-256 dalam manifest; validasi 604 halaman, urutan surah/ayat/kata dan relasi baris; bandingkan halaman awal/tengah/akhir serta batas surah/juz dengan cetakan guru; minta guru kompeten meninjau visual dan teks. Baru setelah itu tandai edisi `validated`/`active` sesuai ERD. Hak repo kode tidak otomatis mencakup aset data/font.
